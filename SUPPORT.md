# Support

Background Remover is a source-available, local-first project. The best support path is a GitHub issue with enough detail for someone else to reproduce the workflow without private files.

## Before opening an issue

Run the core checks when practical:

```powershell
cd D:\open-source\background-remover
npm.cmd run check
npm.cmd run qa:preview-export
```

## Good bug reports include

- Browser and operating system.
- Source image type and rough dimensions.
- Selected model, preset, scene, shadow settings, and review overlay.
- Whether the problem affects preview, selected export, ZIP export, or the export history.
- Non-private screenshots or terminal output.

Please do not attach private product photos, credentials, tokens, customer files, or images you do not have permission to share.

## Feature requests

Useful feature requests describe the real workflow first: marketplace listing, product catalogue, profile image, creator thumbnail, batch export, review, or local deployment.

The project should stay:

- Local-first by default.
- Free from credit-based hosted processing.
- Reproducible with public source and public-compatible assets.
- Consistent with the PolyForm Noncommercial public license and commercial-use notice.
